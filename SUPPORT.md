# Support

These projects are maintained by one person in their spare time. There is no paid support and no
guaranteed response time.

| You want to                      | Go to                                                                                                                    |
| -------------------------------- | ------------------------------------------------------------------------------------------------------------------------ |
| Report a bug                     | A new issue in the affected repository, using the **Bug report** form                                                    |
| Propose a feature or change      | A new issue in the affected repository, using the **Feature request** form                                               |
| Ask how to use a project         | A new issue in the affected repository, using the **Question** form, after reading its README                            |
| Report a security vulnerability  | Private vulnerability reporting; see the [Security Policy](https://github.com/TimSchoenle/.github/blob/main/SECURITY.md) |
| Report a Code of Conduct concern | The contact in the [Code of Conduct](https://github.com/TimSchoenle/.github/blob/main/CODE_OF_CONDUCT.md)                |

Before opening an issue, search the existing open and closed issues. A duplicate is closed with a
link to the original.
